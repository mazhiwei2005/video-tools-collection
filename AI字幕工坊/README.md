# AI动漫字幕工坊 v1.0

专业级AI动漫字幕工作站

## 🚀 快速开始

### 方法1: 双击启动
直接双击 `start.bat` 启动

### 方法2: 命令行启动
```bash
python main.py
```

## 📦 依赖安装

```bash
pip install translators
```

## 🌐 支持的翻译引擎

| 引擎 | 状态 | 说明 |
|------|------|------|
| 搜狗翻译 | ✅ 可用 | 免费，速度快 |
| 必应翻译 | ✅ 可用 | 免费，质量高 |
| 阿里翻译 | ✅ 可用 | 免费，稳定 |
| 有道翻译 | ✅ 可用 | 免费，准确 |
| 彩云小译 | ✅ 可用 | 免费，自然 |
| MiMo AI | ⚙️ 需配置 | 需要API Key |
| Ollama | ⚙️ 需安装 | 本地运行 |

## 🎯 翻译风格

- **动漫字幕组** - 自然流畅，适合动漫
- **直译** - 保持原意，准确翻译
- **B站风格** - 接地气，符合B站用户习惯
- **轻小说** - 优美文艺，适合文学作品
- **日常口语** - 自然随意，日常对话

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+O | 打开视频 |
| Ctrl+S | 保存字幕 |
| 空格 | 播放/暂停 |
| 左箭头 | 上一条字幕 |
| 右箭头 | 下一条字幕 |

## 📁 支持格式

### 视频格式
- MP4, MKV, AVI, MOV, FLV

### 字幕格式
- SRT, ASS, VTT

## 📝 使用说明

1. **打开视频** - 点击"打开视频"或按Ctrl+O
2. **打开字幕** - 点击"打开字幕"加载SRT/ASS文件
3. **AI翻译** - 选择引擎和风格，点击"AI翻译"
4. **保存字幕** - 点击"保存字幕"或按Ctrl+S

## 🔧 配置文件

编辑 `config.json` 可以修改默认设置:
- 默认翻译引擎
- 默认翻译风格
- 源语言/目标语言
- Whisper模型配置

2. 已安装 translators 库
